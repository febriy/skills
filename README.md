# My skills

My own standalone, invokable skills — the ones that aren't part of the [factory](https://github.com/febriy/factory) development pipeline. Each is a plain command I run when I want it.

| Skill | What it does |
|-------|--------------|
| [`design/ui-flow`](design/ui-flow/SKILL.md) | Worktree-based UI design exploration — lo-fi to hi-fi mockups. |
| [`product/socratic-pm-coach`](product/socratic-pm-coach/SKILL.md) | Pressure-test a build idea Socratically before any code; ends in a sharpened user story + an LLM story with acceptance criteria. |
| [`learning/build-with-me`](learning/build-with-me/SKILL.md) | Walk me through an existing artifact one concept at a time, each step ending in a check question. |

## Install

```bash
npx skills add febriy/skills --skill socratic-pm-coach
npx skills add febriy/skills --skill build-with-me
npx skills add febriy/skills --skill ui-flow
```
